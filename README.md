# userscripts
Userscripts for e.g. Tampermonkey

To defend against web annoyances.

##Usage: 
1. Install Tampermonkey Extension on your browser.
2. Paste the script URL to browser URL bar, in format https://raw.githubusercontent.com/karimonkala/userscripts/main/<script-name.js>
3. Tampermonkey will notice this, and prompt to install the script. It's up to you if you trust the script.
